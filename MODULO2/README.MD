# MÓDULO 2
## Asistente de Redacción con IA para planes y proyectos
Mediante la herramienta Gemini Notebook realizamos la Selección y Evaluación del Tema para el Proyecto Final, como un entorno de investigación comparar propuestas, permitiéndonos tomar una decisión fundamentada.
Primero buscamos información de las 3 alternativas para enviarlas como fuente a Gemini Notebook, para que luego analice si la información es suficiente para desarrollar el proyecto. Continuamos utilizando la IA para que haga un Análisis de Viabilidad y Complejidad Técnica. Por último, el equipo tuve que enviar un párrafo de cada integrante justificando sus fortalezas técnicas e intereses laborales, para que Google Gemini realice una evaluación de Alineación Vocacional e Impacto Profesional.
La IA construye la matriz de decisión y nos dará la Elección Final.
